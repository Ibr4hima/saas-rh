# ADR-0107 : La déclaration de mouvement cite le Code du travail de 1997, comme les autres documents

**Statut** : acceptée · 2026-10-18 · précise l'[ADR-0106](0106-declaration-de-mouvement.md)

## Contexte

L'ADR-0106 mettait la déclaration de mouvement du travailleur au Code du
travail de 2026 (loi n° 2026-18 du 3 septembre 2026). Les autres documents
de la DCH citent encore la loi n° 97-17 du 1er décembre 1997, comme les
modèles de l'APIX. La DCH décidera du passage au nouveau Code avant qu'il se
fasse.

## Décision

**La déclaration reprend les textes de son modèle**, ses coquilles corrigées
(ADR-0095) :

- les références : l'article L.222, alinéas 2 à 5, du Code du travail (loi
  n° 97-17 du 1er décembre 1997), et l'arrêté n° 7301 du 17 mai 1963 ;
- le visa d'approbation par l'inspecteur du travail et de la sécurité
  sociale, et le visa d'enregistrement à la section locale du service de la
  main-d'œuvre, dont le nom se porte à la main ; le visa d'approbation se
  renseigne pour toute personne ;
- la première note : le troisième exemplaire se dépose, dans l'intérieur, à
  la section locale du service de la main-d'œuvre, à l'inspection régionale
  du travail et de la sécurité sociale du ressort ; à Dakar, au Bureau
  central du service de la main-d'œuvre.

La date de départ d'un travailleur qui quitte l'établissement reste :
l'article L.222 la demande aussi. L'arrêté garde son titre exact et sa
publication d'après NATLEX (JO n° 3610 du 22 juin 1963, p. 835).

**La fiche se précise** :

- l'autorité qui délivre la carte d'identité n'est plus préremplie ; elle
  reste obligatoire ;
- la catégorie d'enregistrement devient facultative ; sans elle, aucune
  lettre n'est encadrée ;
- le numéro au fichier central s'intitule « N° d'immatriculation au FCMO »
  dans la fiche ; le formulaire garde son libellé complet.

## Conséquences

- Le passage au Code du travail de 2026 se fera pour tous les documents
  ensemble, quand la DCH l'aura décidé ; l'ADR-0106 dit ce qu'il changerait
  dans la déclaration.
