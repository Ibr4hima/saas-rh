# Code du travail — transcription

Transcription mot pour mot du texte officiel (PDF scanné), partie par partie.
Rien n'est corrigé : orthographe, ponctuation, majuscules et apostrophes
(’ ou ') sont celles du document.

Conventions :

- `%% page N` : début de la page N du document (numéro imprimé) — repère de
  vérification, ignoré à l'import ;
- `TITRE …`, `Chapitre …`, `Section …`, `Article N.- Intitulé` : la structure ;
- `- ` : tiret d'une énumération ; `  1. `, `  a) `, `  • ` : sous-énumération ;
- `**…**` : gras du document (termes définis) ; `*…*` : italique.

Vérification : chaque page est relue contre le scan agrandi, puis comparée mot
à mot à une reconnaissance optique indépendante (`verifier-ocr.py`, Tesseract
fra) ; chaque écart est contrôlé à l'œil.
